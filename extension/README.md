# local music · B站收藏（浏览器插件）

逛 B 站时一键把音乐视频收藏到 local music，不用复制粘贴链接。支持多P合集整辑收藏。

**并且不需要先启动 local music**：绑定一次本地项目目录后，插件会把收藏直接写进项目里，
下次启动 local music 时自动收进曲库。

## 两种收藏通道（插件自动选）

| 情况 | 收藏去哪 |
|------|----------|
| local music 正在运行 | 直接调本地接口，立刻进曲库（还能顺手下载、补封面） |
| local music 没运行，但已绑定项目目录 | 插件自己抓 B 站信息，写进项目目录的 `data/extension-inbox.jsonl`，**下次启动时自动导入** |
| 都没做 | 提示你先启动服务，或去绑定项目目录 |

弹窗右上角会显示当前处于哪种状态：`已连接` / `离线模式` / `未启动`。

## 安装

1. 打开浏览器的扩展管理页：地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角的「**开发者模式**」开关
3. 点击左上角「**加载已解压的扩展程序**」，选择本目录（`extension/` 文件夹）
4. 工具栏出现粉色心形图标即安装成功（建议点📌固定到工具栏）

> Firefox 暂不支持（清单格式不同）。Safari 不支持。

## 绑定本地项目目录（可选，推荐）

弹窗 →「本地项目目录」→ **绑定本地项目目录**，会打开设置页：

1. 点「选择 local music 项目文件夹」
2. 选中**项目根目录**（含 `app.py`、`static/` 的那个文件夹）；
   如果你用的是打包版，选**数据目录**（含 `music.db`，macOS 一般在 `~/Library/Application Support/localmusic`）
3. 浏览器询问读写权限时选「允许」

绑定后：

- 不启动 local music 也能在 B 站随手收藏，收藏会排队等你启动
- 弹窗里能看到「待同步 N 条」
- 下次启动 local music，或在曲库页面刷新一次，这些收藏会自动导入（前端会提示「已从浏览器插件同步 N 首收藏」）
- 重复收藏不会产生重复条目
- 如果某天提示「需重新授权」，回到设置页重新选一次同一文件夹即可

> 注意：**播放和下载音乐仍然需要启动 local music**（音频流由本地服务提供），
> 离线收藏只是让你"收藏"这个动作不再依赖服务。

## 使用方式

| 方式 | 操作 | 说明 |
|------|------|------|
| 悬浮按钮 | 视频页右下角的粉色心形按钮 | 单P点击直接收藏；多P会弹出面板让你选「仅这一集」或「整个合集」。按钮可以**按住拖动**换位置，会记住 |
| 工具栏弹窗 | 点扩展图标 | 显示连接状态、当前视频收藏按钮、绑定目录、右键菜单默认模式、服务地址等设置 |
| 右键菜单 | 在视频页 / 链接上右键 →「收藏到 local music」 | 按「默认模式」直接收藏（弹窗里可改成：自动 / 只收单集 / 收整个合集） |

已在曲库中（或已排队）的视频，悬浮按钮会亮**绿点**；重复收藏不会产生重复条目，会提示「曲库里已经有了」。

## 服务没在运行？

- 想直接入库、下载音频：先启动 local music（`./start.sh` / `start.bat`）
- 只想收藏：绑定项目目录后可以直接用，收藏会排队等下次启动

## 常见问题

- **服务换了端口**：在弹窗的「服务地址」里改成 `http://127.0.0.1:端口号` 即可。
- **不想看到悬浮按钮**：弹窗里关掉「视频页显示悬浮按钮」，只用工具栏弹窗和右键菜单。
- **更新插件**：改完代码后在 `chrome://extensions` 里点该插件的「重新加载」，B站页面也要刷新一次。
- **插件能看我的曲库吗**：接口只对本机与浏览器扩展开放 CORS，外部网站的请求会被拒绝；目录访问也由浏览器逐次授权，所有数据都在你自己的电脑上。

## 文件结构

```
extension/
├── manifest.json      # MV3 清单
├── background.js      # 后台：请求代理、双通道收藏、右键菜单、角标反馈
├── content.js         # B站页面：悬浮按钮、合集选择面板、toast（Shadow DOM）
├── fsaccess.js        # 项目目录绑定与读写（File System Access API，SW 与页面共用）
├── setup.html/js      # 绑定目录的设置页（独立标签页，避免 popup 被系统对话框关掉）
├── popup.html/js/css  # 工具栏弹窗
├── icons/             # 图标（make_icons.py 生成）
└── make_icons.py      # 图标生成脚本（纯 Python，无依赖）
```

插件写出的 `data/extension-inbox.jsonl`（每行一条 JSON）由后端在启动时导入，
导入后归档到 `data/inbox/imported-时间戳.jsonl`，可随时查看或删掉。
